Slicer Setup & Kintsugi Guide

What KintsugiVase does

It combines two slices of the same, unmoved model: a normal multi-wall Standard base and a continuous Vase slice. You choose each handoff height and the app generates aligned transition G-code plus a complete preview.

Required slicer preparation

Both files

  • Use the same model, plate position, scale, layer height, nozzle, and origin.
  • Enable Verbose G-code. In Orca/Bambu: Others → G-code output → Verbose G-code.
  • Use an aligned/back seam. Keep the outer profile continuous near every junction.
  • Prefer .gcode.3mf so thumbnails and LAN-print metadata survive export.

Slice-specific settings

  • Standard base: normal walls/infill; concentric top surfaces give the vase wall a continuous landing path.
  • Vase: enable Spiral Vase and, when available, Smooth Spiral.
  • Choose conservative wall speed, temperature, and cooling for the first physical test.

Workflow, order, and layers

  1. Drop the two matching files into their boxes, or choose a bundled demo pair and click Load pair.
  2. Choose whether the print begins with Base or Vase. Each transition alternates the source, so two heights can produce Base → Vase → Base or Vase → Base → Vase.
  3. Add transition heights. Typed values snap to real base layers; Up/Down moves to adjacent layers. The vertical Z control and Set Trans. set the selected row.
  4. Click Splice & Generate Preview. If a direction change makes a layer unusable, the app searches for the nearest valid layer and reports the correction.
  5. Inspect every junction, then save plain .gcode or metadata-preserving .gcode.3mf.

Transition Engine settings

Level Bonding / Support Loop
Base→Vase prints a complete flat outer-wall loop before the spiral climbs. Vase→Base flattens the final spiral turn and adds a complete support rim under the incoming base layer.
Hop / Travel / Prime speeds
Fallback movement values used only when a direct matched handoff cannot be made. Strict matched planar junctions avoid XY travel and retraction at the seam.
Flow Taper
Ramps extrusion from the chosen starting percentage to full flow across the specified contour distance, reducing a sudden bead-size step.
Seam Matching
Relocates the handoff to a common point on both paths. Search Layers Before/After control the vertical search window; Base→Vase remains forward-only to prevent duplicate material below the boundary.
Scarf Lap Joint
Overlaps complementary tapering beads across the selected distance to strengthen and hide the seam.
Tangential Lead-In
Approaches from inside the part and wipes tangentially onto the perimeter. Lead-In Offset controls that inside distance.

Flow and wall controls

  • Vase Flow Multiplier: scales all vase extrusion.
  • Wall Thickness Tuning: detects the sliced vase width and scales flow toward Target Vase Width. Confirm the requested width is realistic for the nozzle.

Advanced tuning

  • Speed Tuning: applies Slow Speed as a step or smooth ramp across the chosen layers before/after.
  • Transition Temp/Fan: overrides nozzle temperature or fan only around the junction; blank means source defaults.
  • Bed X/Y: sizes the preview grid. Material Density affects only the estimated weight.

Per-junction editing and custom G-code

Select a transition row, then open Selected Junction. Each junction can override shared transition values. The generated block is inspectable; advanced users may insert code before/after it or replace it. Reserved Kintsugi markers are protected. Custom commands are executed by the printer, so review the final preview and exported text.

Preview controls

  • Color Mode: Base/Vase, speed, flow, width, layer height, or temperature. The selected mode persists after resplicing.
  • Vertical Z: filters the preview by layer. Mouse wheel and Up/Down step layers.
  • LayerBuild: reveals moves within only the selected layer; Left/Right steps those moves.
  • Playback: animates extrusion at selectable speed. Inspect Junction zooms to the selected handoff and plays it.
  • Camera: left-drag rotates, right/middle-drag pans, wheel zooms, and Home restores the view.

Errors and validation

  • No layers: re-export with verbose G-code.
  • No complete outer contour: check aligned seams, continuous geometry, and feature comments.
  • Files never reach Z: choose a height present in both slices.
  • Transitions too close: leave enough vertical space for complete reconstructed turns.
  • Software checks geometry and G-code consistency; adhesion and watertightness require a supervised print and leak test.

Warning & Disclaimer

Generating and executing custom, spliced G-code can result in unexpected toolhead movements.

Use this tool entirely at your own risk. The creator assumes absolutely no responsibility for any damage to your 3D printer, failed prints, wasted filament, or any other negative outcomes resulting from the use of this software.

Please refer to the Setup Guide and always closely supervise your 3D printer during the transition layers when testing new files.
